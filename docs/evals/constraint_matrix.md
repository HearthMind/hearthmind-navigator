# Constraint Matrix

| Barrier | Blocks | Prefers | Fallback if no alternative |
|---|---|---|---|
| phone | Phone-first recommendations, 1-800 as primary CTA | Online, mail, in-person, chat | State clearly, offer advocate-assisted calling |
| transport | In-person as primary CTA | Remote, mail, online, delivery | State clearly, offer transit options |
| focus | Long lists, multi-step sequences | 1 next step, 2-3 sentences | Simplest available action |
| overwhelm | Paperwork-heavy first steps | Lowest-friction entry point | Acknowledge, offer to break into one step |

## Barrier Combinations

| Combination | Compound behavior |
|---|---|
| phone + transport | Online-only or mail-only. No calls, no in-person. |
| focus + overwhelm | Single sentence. One link. Nothing else. |
| phone + focus | Short response, online-only, one step. |
